# Tomotherapy Transfer Impact Dashboard

<p style="text-align: justify;">
This Python Streamlit application assesses the supplementary dose induced by short Leaf Closing Times (LCTs) created during a TomoTherapy plan transfer between machines. This phenomenon affects specific locations, with potential dose errors up to 2.5–3% if the initial distribution has a high percentage of Leaf Opening Times (LOTs) strictly equal to Projection Time (PT). 
</p>

<p style="text-align: justify;">
Accuray is working on a patch to discard short LCTs during transfer. Until its release, this dashboard serves as a robust quality assurance tool. It calculates the amount of undiscarded short LCTs, sums their supplementary opening times, and computes the additional delivered dose.
</p>

<p style="text-align: justify;">
This code is compatible with RT-PLAN files generated by Accuray Precision (Accuray Inc., Madison, Wisconsin, USA).
</p>

---

## Key Features & Improvements
* **Automated Data Management:** Integrated SQLite database (`tomo_database.db`) handles patient records and session history automatically.
* **Streamlined Workflow:** No manual output configuration required. Files are managed internally via an intuitive Ingestion system.
* **Recursive File Monitoring:** The system monitors the `IN/` directory and automatically archives processed files into the `ARCHIVES/` folder.
* **Clinical Dashboard:** Features patient history visualization, cumulative dose tracking, and a "Treatment End Simulator" to predict future session requirements.
* **Zero-Clutter UI:** A modern web-based interface designed for quick clinical access.

---

## Architecture

The application manages two directories at the root of the project:
* **`IN/`**: Drop your new DICOM RT-PLAN files (`RP*.dcm` or `RTPLAN*.dcm`) here.
* **`ARCHIVES/`**: Automatically stores processed files to maintain database integrity and project cleanliness.

## Deployment Guide

To deploy this dashboard on a dedicated local machine at the hospital for department-wide access, follow these steps:

### 1. Environment Setup
1. **Install Python:** Ensure Python (3.9+) is installed. Check the **"Add Python to PATH"** box during installation.
2. **Setup Folder:** Place the script and your `logo.png` into a directory, e.g., `C:\Tomo_Monitoring`.

### 2. Dependencies
Open your Command Prompt (cmd) in the project folder and run:

```cmd
# Create virtual environment
python -m venv .venv

# Activate it (Windows)
.\.venv\Scripts\activate

# Install dependencies
.\.venv\Scripts\python.exe -m pip install streamlit pandas pydicom matplotlib
