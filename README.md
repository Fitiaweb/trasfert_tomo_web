# Tomotherapy Transfer Impact Dashboard

<p style="text-align: justify;">
This Python Streamlit application assesses the supplementary dose induced by short Leaf Closing Times (LCTs) created during a TomoTherapy plan transfer between machines. This phenomenon only affects a few locations, but the dose error can be up to 2.5-3% if the initial distribution has a high percentage of Leaf Opening Times (LOTs) strictly equal to Projection Time (PT). 
</p>

<p style="text-align: justify;">
Accuray is working on a patch to discard short LCTs during transfer (as it is already done during the End Of Planning process when optimizing a plan). This script can be used until the patch is officially released. 
</p>

<p style="text-align: justify;">
It calculates the amount of undiscarded short LCTs and sums their supplementary opening times to compute the relative value of additional dose. It supposes a homogeneous distribution of short LCTs through the plan, which is a valid approximation for simple PTV locations (e.g., pelvis, bone metastasis...) though it may vary for complex PTV locations (e.g., breast, H&N...).
</p>

<p style="text-align: justify;">
This code only works with RT-PLAN files generated by Accuray Precision (Accuray Inc., Madison, Wisconsin, USA). 
</p>

## Architecture & Workflows

The application automatically manages two local directories at the root of the project:
* **`IN/`**: Place new incoming DICOM RT-PLAN files (`RP*.dcm`) here.
* **`OUT/`**: Once processed by clicking "Traiter les nouveaux plans", files are automatically archived here to maintain a clean database and compile patient history.

## Deployment: How to Run as a Local Network Server

To deploy this dashboard on a dedicated local machine (Server PC) at the hospital and allow all other computers in the department network to access it via a web browser, follow these steps:

### Step 1: Environment Setup (On the Server PC)
1. **Install Python:** Ensure Python (3.9+) is installed. Crucial: check the "Add Python to PATH" box during installation.
2. **Project Folder:** Place Transfer_impact.py (and the logo image if applicable) into a clean folder, e.g., C:\QA_Tomo.

### Step 2: Virtual Environment & Dependencies
Open the Windows Command Prompt (cmd) and navigate to your folder:
cd C:\QA_Tomo

Create a clean virtual environment:
python -m venv .venv

Active the environment:
.\.venv\Scripts\activate

Install all required clinical and web dependencies securely inside the environment:
.\.venv\Scripts\python.exe -m pip install streamlit pandas pydicom openpyxl

### Step 3: Launching the Server
Start the local server using the absolute secure path:
.\.venv\Scripts\python.exe -m streamlit run Transfer_impact.py

(On this very first run, the script will automatically generate the IN/ and OUT/ folders inside your directory).

A browser window will open on the host PC. In the command prompt window, note down the Network URL address (it looks like http://192.168.X.X:8501). Keep this command prompt window open to ensure the server remains active.

### Step 4: Remote Access from Other Workstations
To access the dashboard from any other computer in the hospital department connected to the same local network:
1. Open any modern web browser (Google Chrome, Microsoft Edge).
2. Type the Network URL (e.g., http://192.168.X.X:8501) directly into the address bar and press Enter.

> ⚠️ **Troubleshooting Note:** If remote computers cannot load the page, check the Windows Firewall settings on the Server PC and ensure that inbound connections are authorized for Streamlit/Python.
