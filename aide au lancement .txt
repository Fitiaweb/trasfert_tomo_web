Guide d'installation du Serveur Local - Suivi Doses Tomo

Étape 1 : Préparer le terrain sur le nouveau PC
1. Installer Python : Téléchargez Python sur le site officiel (python.org). Lors de l'installation, cochez impérativement la case "Add Python to PATH" en bas de la première fenêtre.
2. Transférer les fichiers : Créez un dossier dédié sur le PC (par exemple C:\QA_Tomo) et placez-y uniquement votre fichier Transfer_impact.py (et l'image du logo).

Étape 2 : Créer l'environnement virtuel
Ouvrez l'invite de commande (cmd) de Windows et déplacez-vous dans votre dossier :
cd C:\QA_Tomo

Créez ensuite la "bulle" isolée avec la commande suivante (utilisez "py -m venv .venv" si le mot python ouvre le store) :
python -m venv .venv

Activez cette bulle pour vous y placer :
.\.venv\Scripts\activate

Étape 3 : Installer les dépendances (Méthode directe sécurisée)
Tapez cette commande avec le chemin complet pour forcer l'installation au bon endroit, sans interférence de Windows :
.\.venv\Scripts\python.exe -m pip install streamlit pandas pydicom openpyxl

Étape 4 : Lancer le serveur local (Méthode directe sécurisée)
Démarrez l'application avec la commande d'exécution absolue :
.\.venv\Scripts\python.exe -m streamlit run Transfer_impact.py
(C'est lors de ce tout premier lancement que l'application va créer automatiquement et proprement les dossiers IN et OUT dans votre dossier).

Le navigateur du PC va s'ouvrir. Dans la fenêtre noire du terminal, notez précieusement l'adresse appelée Network URL (qui ressemble à http://192.168.X.X:8501). Laissez cette fenêtre noire ouverte et réduite pour que le serveur reste allumé.

Étape 5 : Accéder à l'application depuis le réseau (L'Oncopole)
Pour vous connecter depuis n'importe quel autre ordinateur du service branché sur le même réseau :
1. Ouvrez un navigateur web (Chrome ou Edge).
2. Entrez l'adresse Network URL notée précédemment dans la barre d'adresse et validez.
(Si la page ne se charge pas, vérifiez sur le PC Serveur qu'une fenêtre du Pare-feu Windows ne vous demande pas d'Autoriser l'accès).
